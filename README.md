# Yousstena Melad - Netflix Clone

A responsive front-end Netflix landing page recreation built with HTML, CSS, Bootstrap 5, and JavaScript.

## Pages
- `index.html` — landing page, feature sections, FAQ, footer
- `login.html` — sign-in form
- `register.html` — registration form

## Run locally
Open `index.html` in a browser. Internet access is needed for Bootstrap and Google Fonts CDN assets.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, for example `netflix-clone`.
2. Upload all project files and folders (keep `index.html` in the repository root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then press **Save**.
6. Wait for GitHub Pages to publish. The website link will appear in the Pages section and will look like `https://YOUR-USERNAME.github.io/netflix-clone/`.

## Note
This is a front-end educational demo. Login and registration are visual demonstrations only; no passwords or personal data are transmitted or stored.
